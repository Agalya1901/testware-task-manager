# Testware Task Manager

A full-stack Task Manager application built as part of the Testware Informatics Capstone Project.

## Features
- View all tasks
- Add new tasks
- Mark tasks as completed or pending
- Delete tasks
- Display total, completed and pending task counts

## Technologies Used
- Frontend: React, Vite, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- API: REST API
- Version Control: Git and GitHub
- Frontend Hosting: Vercel
- Backend Hosting: Render

## Live Application
https://testware-task-manager-nu.vercel.app/

## Backend API
https://testware-task-manager.onrender.com/api/tasks

## Run Locally

### Backend
```bash
cd server
npm install
npm start
```

### Frontend
```bash
cd client
npm install
npm run dev
```

## Project Structure
- `client/` – React frontend
- `server/` – Node.js and Express backend
